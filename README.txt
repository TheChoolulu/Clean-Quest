CLEAN QUEST v1

Files:
- index.html: the app
- manifest.json: lets supported browsers install it like an app

Quick test:
Open index.html in a browser.

Hosting:
Upload BOTH files to the root of a static website host. The site must serve them over HTTPS for the best install experience.

Important:
Progress is stored in the browser on that device using localStorage. Clearing site/browser data can erase progress.

Game rules:
- Required tasks determine the Friday victory condition.
- Optional side quests do not affect required completion.
- Husband/team tasks are tracked separately and do not affect your personal required completion percentage.
- Large tasks can be Not Started, In Progress, or Complete.
- Hidden Easter eggs award prestige points and are not revealed in advance.
