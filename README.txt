CLEAN QUEST v2

Upload index.html and manifest.json to the ROOT of your existing clean-quest GitHub repository and replace the existing versions.

v2 improvements:
- Room counts show required tasks only, so optional Side Quests no longer distort room readiness.
- Team Tasks are clearly marked TEAM · REQUIRED.
- Team Tasks count toward whole-house victory and zone clearing, but their points stay separate from personal points.
- Partial progress moves the mission bar; beer unlock requires every required task to be fully complete.
- Duplicate upstairs vacuum scoring was removed. 'Vacuum all upstairs rooms' is the single 12-point upstairs vacuum quest.
- Existing completion states are migrated by task name and zone when v2 first loads.
- Hidden Easter egg triggers remain hidden.
